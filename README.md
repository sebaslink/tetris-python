# Tetris en Python con Tkinter

Un juego clásico de Tetris desarrollado en Python utilizando **Tkinter** para la interfaz gráfica y la biblioteca estándar de Windows para efectos de sonido.

## Características

- 🎮 **Controles fluidos**: Movimiento lateral, rotación y caída rápida.
- 💾 **Pieza Reservada (Hold System)**: Presiona la tecla `C` para guardar una pieza o intercambiarla.
- 👁️ **Vista Previa de Siguiente Pieza**: Muestra cuál será el próximo bloque en aparecer.
- 📊 **Sistema de Puntuación y Niveles**: Los niveles avanzan del 1 al 10 cada 1000 puntos, incrementando la velocidad de caída.
- 🏆 **Récord Máximo**: Registro de máxima puntuación y pantalla especial de **¡NUEVO RÉCORD!**.
- 🔊 **Efectos de Sonido**: Sonidos del sistema de Windows para movimientos, rotación, líneas eliminadas y Game Over.
- 🔄 **Reinicio Rápido**: Presiona `R` en cualquier momento o tras Game Over para reiniciar la partida.

## Requisitos y Ejecución

Requiere Python 3.x instalado en Windows:

```bash
python tetris.py
```
